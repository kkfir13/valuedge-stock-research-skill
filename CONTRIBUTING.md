# Contributing to Buffett Brain

Submit short **original** historical summaries with source URLs, exact year, section/page or video timecode, and clear separation of documented facts, interpretation and limitations. Avoid invented Buffett quotes, unsourced motives and copied copyrighted letters/books/transcripts. The project is independent and free to run.

To contribute: update `knowledge/atlas.json`; include a new verified source only when needed, run `python3 scripts/validate_knowledge.py` and `python3 -m unittest discover -s tests -v`, then submit a pull request. See the research coverage backlog at https://github.com/kkfir13/valuedge-stock-research-skill/issues/6.
